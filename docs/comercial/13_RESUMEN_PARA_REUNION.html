Selección

Ocho preguntas, 16 puntos

  • Acceso al propietario
  • Frecuencia
  • Dolor observable
  • Compatibilidad actual
  • Responsable operativo
  • Mantenimiento de datos
  • Aceptación del piloto
  • Aceptación del precio

12–16: incorporar. 9–11: nutrir o probar problema. 0–8: descartar por ahora.

Escala interna: 0, 1 o 2 por criterio. Aceptar el precio verbalmente no equivale a pagar.

Límites

Lo que no se vende

Funciones ausentes

Pagos, domicilios, inventario, facturación, POS, órdenes de taller, historia clínica y WhatsApp automático.

Promesas prohibidas

Aumento de ventas, ahorro garantizado, integración futura, desarrollo a la medida o liderazgo de mercado.

Si una función ausente es indispensable, no se incorpora el negocio.
